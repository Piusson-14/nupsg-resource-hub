# NUPS-G Resource Hub

A modern, mobile-first resource-sharing platform for students of the National Union of Presbyterian Students – Ghana.

## Features

- Hero section with animated counters
- Instant search across resources
- Category and filter controls
- Resource cards with download and detail actions
- Upload experience with drag-and-drop support
- Responsive layout built with React, Vite, Tailwind, Framer Motion, and Supabase-ready APIs

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Environment variables

Create a `.env` file with:

```bash
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```
